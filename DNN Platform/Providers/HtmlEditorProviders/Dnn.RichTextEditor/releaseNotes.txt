<h3>Rich Text Editor Provider</h3>
<ul>
	<li>New HTML editor provider based on the MIT-licensed Jodit editor (v4.18.10), replacing CKEditor 4 for new installations.</li>
	<li>Exposes an editor-neutral JavaScript API (<code>dnn.richTextEditor</code>) for modules that need to interact with the editor.</li>
	<li>Image and file browsing and uploading through the <code>/API/RichTextEditor/FileBrowser</code> service, which applies the user's DNN folder permissions to every request. Uploads made straight from the editor go to the folder in the provider's <code>uploadFolder</code> attribute (the portal root by default).</li>
</ul>
